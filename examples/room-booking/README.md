# Example: the first live run

The full, unedited output of BusinessAnalysisTeam's first live run (2026-10-10). The brief is
[`brief.md`](brief.md), a made-up library that wants online study-room booking.

**Start with [deliverables/README.md](deliverables/README.md)**, the page the owner is shown once QC
awards A.

| Folder | What's in it |
|---|---|
| `elicitation/` | The analyst's questions, the owner's reply ("use the defaults"), and the record of every assumption adopted. These 15 questions predate the five-plain-questions rule: the owner's reaction to them is what created it. |
| `deliverables/` | The research report and the requirements specification, both graded A |
| `reviews/` | Each round's mechanical pre-check and the Quality Controller's full report |

How the pack got to A:

| Round | Grade | Findings |
|---|---|---|
| 1 | C | 1 major, 14 minor |
| 2 | C | 1 major, 1 minor |
| 3 | B | 2 minor |
| 4 | B | 1 minor |
| 5 | A | none |

The major finding in round 1: the draft let members sign in with their card number and PIN on a
public page, with no limit on wrong guesses. The run cost $54.18.
